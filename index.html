    Von python.org herunterladen. Bei der Installation „Add Python to PATH“ ankreuzen.

  1. App im Internet bereitstellen (einmalig)

    Den entpackten Ordner auf einen Webspace mit https:// legen, zum Beispiel über GitHub Pages. Eine Anleitung steht in der README.md im ZIP.

  2. Adresse auf dem Handy öffnen

    iPhone: in Safari. Android: in Chrome.

  3. Zum Startbildschirm hinzufügen

    iPhone: Teilen → „Zum Home-Bildschirm“. Android: Menü (⋮) → „App installieren“. Danach läuft die App auch ohne Internet.

Auf dem iPhone die App immer über das Symbol starten. Nur so bleiben die Daten dauerhaft erhalten.

Wichtig: Beim ersten Start legst du ein Profil mit Passwort an. Das Passwort kann nicht wiederhergestellt werden – merke es dir gut.
